# Code Critters: Free Demo

A friendly puzzle game that teaches kids the basics of coding. Guide a little robot to the star by building a program out of simple blocks: move forward, turn left, turn right, and repeat.

**Play the free demo in your browser:** https://alphazolo12200-tech.github.io/code-critters-free-demo/

**Get the full game (12 levels):** https://alphazolozyro.itch.io/code-critters

## What is in the free demo

- The first 4 levels of the game
- Drag-and-drop blocks (or just tap them, which works well on tablets and phones)
- Your first loop, using the Repeat block
- Sound effects, with an on/off button
- Star ratings: use fewer blocks to earn more stars

## What the full game adds

- 12 levels in total, with trickier mazes and bigger loop puzzles
- A grand finale level
- Progress that is saved in your browser

## How to play

1. Drag a block into the "My program" box, or tap it.
2. Tap **Repeat** to make a loop. Blocks you add next go inside the loop. Use + and − to change how many times it runs.
3. Press **Run** and watch the robot go.
4. Tap a block in your program to remove it.

## Who it is for

Kids aged about 6 to 10, plus younger children playing with a parent. It works well at home or in a classroom, on a computer, tablet or phone.

## Run it on your own computer

Download this repository and open `index.html` in any modern browser. No install and no internet connection are needed. The page loads one optional web font when online and falls back to a standard font when offline.
